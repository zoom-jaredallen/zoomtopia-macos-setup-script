The production event wallpapers are 3840×2400 pixels, 16:10, sRGB JPEGs at high quality. This format is broadly compatible with the mixed MacBook fleet and keeps the USB payload compact.

- `wallpaper.jpg`: dark blue default theme.
- `wallpaper-green.jpg`: light green alternative theme.

Select a theme by changing `wallpaperFilename` in `config/setup-config.json`.
