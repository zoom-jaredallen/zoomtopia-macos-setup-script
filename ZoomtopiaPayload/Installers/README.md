Place vendor-supplied installer packages here using these names:

- `GoogleChrome.pkg`, or architecture-specific `GoogleChrome-arm64.pkg` and `GoogleChrome-x86_64.pkg`
- `ZoomWorkplace.pkg`, or architecture-specific `ZoomWorkplace-arm64.pkg` and `ZoomWorkplace-x86_64.pkg`

Use the official Chrome Enterprise PKG and Zoom IT Admin PKG. After adding or replacing files, run `scripts/generate-checksums.sh` from the repository root.
